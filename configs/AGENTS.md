Use `gh-axi` as the preferred tool for GitHub operations and research.

Use `chrome-devtools-axi` only for development tasks that genuinely require browser automation or debugging, such as inspecting a running application, reproducing UI bugs, or analyzing the DOM, console, network, and performance.

Do not use `chrome-devtools-axi` solely for web research or reading public documentation. For those cases, use the appropriate web search/browsing tool.
