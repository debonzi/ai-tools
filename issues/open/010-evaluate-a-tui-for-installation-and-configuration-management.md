## Description

Evaluate whether a terminal UI should complement or replace parts of `install.sh` for managing this repository’s installation and configuration targets. Document the intended workflows, bootstrap and non-interactive requirements, viable implementation options, and how existing validation, safety, and idempotency guarantees would remain authoritative. Finish with a recommendation and a bounded implementation scope; do not add a second independent installation path during this evaluation.
